## Cloud Run AUTOSCALING最適化 (2026-02-21 21:30)

### 問題の発見
ログ中の以下の箇所でAUTOSCALINGによる料金への影響を懸念:
```
2026-02-20T12:00:03.180234Z  INFO  Starting new instance. Reason: AUTOSCALING
```

### 最適化前の設定確認
```bash
gcloud run services describe fx-insight-bot --region=asia-northeast1
```

**設定状況**:
- 最大インスタンス数: 5
- 最小インスタンス数: 0（デフォルト）
- 同時実行数: 80
- CPU: 1000m (1vCPU)
- メモリ: 512Mi
- 起動ブースト: 有効

### 実施した最適化
#### Step 1: スケーリング制限
```bash
gcloud run services update fx-insight-bot \
  --region=asia-northeast1 \
  --max-instances=2 \
  --concurrency=1
```

#### Step 2: リソース削減
```bash
gcloud run services update fx-insight-bot \
  --region=asia-northeast1 \
  --cpu=500m \
  --memory=256Mi
```

### 最適化結果
#### 設定変更
- **最大インスタンス数**: 5 → **2** (60%削減)
- **同時実行数**: 80 → **1** (シンプル化)
- **CPU**: 1000m → **500m** (50%削減)
- **メモリ**: 512Mi → **256Mi** (50%削減)

#### 料金削減効果
- **CPU料金**: 約50%削減
- **メモリ料金**: 約50%削減
- **スケーリング制御**: 無制限拡張を防止

#### 動作確認テスト
```bash
curl -X POST "https://fx-insight-bot-755346299346.asia-northeast1.run.app/api/v1/trade/execute" \
  -H "Content-Type: application/json" -d '{"dry_run":true}'
```

**結果**: ✅ 正常動作確認（レスポンス時間・機能ともに問題なし）

### 注意事項
- **コールドスタート**: 最小インスタンス0のため、リクエスト時に起動時間が発生
- **監視ポイント**: パフォーマンス、エラー率、起動時間の変化要確認
